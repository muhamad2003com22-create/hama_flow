# پلاتفۆرمی یاری hama.flow بە زمانی کوردی

وێبسایت و پلاتفۆرمی مۆدێرنی یاری زیرەکی **hama.flow** بە دیزاینی تایبەت بۆ بەکارهێنەران و پەخشی ڕاستەوخۆ (لایڤی تیکتۆک و یوتیوب).

---

## ⚡ گرنگ: چاککردن و بەستنەوە بە Supabase (بۆ لایڤ و هەموو مۆبایلەکان)

ئەگەر یارییەکەت لەسەر **GitHub Pages**، **Vercel**، یان هەر ماڵپەڕێکی تر هۆست کردووە و دەتەوێت کۆدەکان و ئەنجامەکان ڕاستەوخۆ بگەنە مۆبایلی بینەران، تەنها ئەم ٣ هەنگاوە بکە:

### هەنگاوی ١: دروستکردنی پڕۆژە لە Supabase
1. بڕۆ بۆ [supabase.com](https://supabase.com) و هەژمارێکی بێبەرامبەر بکەرەوە (دەتوانیت بە گیتھەب بچیتە ژوورەوە).
2. کلیک بکە لەسەر **New Project**، ناوێک بۆ پڕۆژەکە دابنێ (وەک `hama-flow`) و پاسۆردێک بنووسە.

### هەنگاوی ٢: جێبەجێکردنی خشتەکان (SQL Schema)
1. لە لیستی لای چەپی Supabase، کلیک لەسەر **SQL Editor** بکە.
2. تەواوی ناوەڕۆکی فایلی `supabase_setup.sql` کۆپی بکە (یان لە ناو پانێڵی ئەدمین کلیک لەسەر دوگمەی سەوزی **📋 کۆپیکردنی کۆدی SQL** بکە).
3. لەناو SQL Editor پیستی بکە و دوگمەی سەوزی **Run** دابگرە.

### هەنگاوی ٣: دانانی URL و Anon Key
1. لە چەپی Supabase بڕۆ بۆ **Project Settings** > **API**.
2. بەهای **Project URL** و کلیلی **anon / public key** کۆپی بکە.
3. بڕۆ بۆ پانێڵی ئەدمین لە وێبسایتەکەت (`admin.html`)، لە بەشی ڕێکخستنی Supabase دایانبەنێ و کلیک لەسەر **💾 پاشەکەوتکردن** بکە.
   *(یان دەتوانیت لە فایلی `public/js/supabase-config.js` ڕاستەوخۆ بنووسیت و بیخەیتە سەر GitHub).*

🎉 **ئێستا سیستەمەکە سەد لە سەد ئامادەیە:**
* هەر کۆدێک دروست بکەیت لە هەمان چرکەدا دەچێتە سەر مۆبایلی هەموو بینەران.
* هەر یاریزانێک یەکەم بێت، بە ڕاستەوخۆ (Realtime) تاجی زێڕینی پێدەدرێت و لەسەر شاشەی ئەدمین دەردەکەوێت!

---

## 🌟 تایبەتمەندییە سەرەکییەکان

### ١. دروستکردنی کۆدی هەڕەمەکی و ژووری زۆر (Bulk Code Generator)
* ئەدمین دەتوانێت بە یەک کلیک ٥، ١٠، ٢٠، ٥٠ یان ١٠٠ کۆدی ژووری جیاواز دروست بکات.
* دوگمەی **📋 کۆپیکردنی هەموو کۆدەکان** بۆ بڵاوکردنەوەی ئاسان لە لایڤدا.

### ٢. یاری تایبەتی ئەدمین (Custom Level Builder)
* ئەدمین دەتوانێت لەڕێگەی ئامرازی Builder لە ناو پانێڵەکەیدا بە دڵی خۆی قەبارەی بۆرد (٥×٥ تا ١٠×١٠) هەڵبژێرێت و یاری نوێ دروست بکات.

### ٣. چوونەژوورەوەی یاریزانان بە کۆد (Player Access Code)
* یاریزانان پێویستیان بە دروستکردنی ئەکاونت نییە!
* تەنها **ناوی یاریزان** لەگەڵ **کۆدی یاری (وەک `FLOW2026` یان کۆدی تایبەتی)** دەنووسن و دەستبەجێ دەچنە ژوورەوە.

### ٤. دەسەڵاتی تایبەتی ئەدمین (Admin Control & Login)
* تەنها بەڕێوەبەر (ئەدمین) دەتوانێت بچێتە ژوورەوە بە ناوی بەکارهێنەر و وشەی نهێنی:
  * **ناوی بەکارهێنەر:** `adminitit`
  * **وشەی نهێنی:** `ititadmin1`
* دەتوانیت وشەی نهێنی و ناوی بەکارهێنەر لە ناو پانێڵەکەش بگۆڕیت.

### ٥. خەڵات و دیاریکردنی کێ یەکەمە؟ (First Finisher Badge)
* یەکەم یاریزان کە بۆردەکە تەواو بکات، بە دەنگی خۆش و تاجی زێڕینی **"👑 پیرۆزە! تۆ یەکەم کەسیت کە ئەم یارییەت تەواو کرد!"** خەڵات دەکرێت.
