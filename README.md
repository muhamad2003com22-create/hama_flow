# پلاتفۆرمی یاری hama.flow بە زمانی کوردی

وێبسایت و پلاتفۆرمی مۆدێرنی یاری زیرەکی **hama.flow** بە دیزاینی تایبەت بۆ بەکارهێنەران و ئەدمین.

---

## 🌟 تایبەتمەندییە سەرەکییەکان

### ١. یاری تایبەتی ئەدمین (Custom Level Builder)
* ئەدمین دەتوانێت لەڕێگەی ئامرازی Builder لە ناو پانێڵەکەیدا بە دڵی خۆی قەبارەی بۆرد (٥×٥ تا ١٠×١٠) هەڵبژێرێت و یاری نوێ دروست بکات.

### ٢. چوونەژوورەوەی یاریزانان بە کۆد (Player Access Code)
* یاریزانان پێویستیان بە دروستکردنی ئەکاونت نییە!
* تەنها **ناوی یاریزان** لەگەڵ **کۆدی یاری (وەک `FLOW2026`)** دەنووسن و دەستبەجێ دەچنە ژوورەوە.

### ٣. دەسەڵاتی تایبەتی ئەدمین (Admin Control & Login)
* تەنها بەڕێوەبەر (ئەدمین) دەتوانێت لەڕێگەی ناوی بەکارهێنەر و وشەی نهێنی Login بکات.
* **ناوی بەکارهێنەر:** `adminitit`
* **وشەی نهێنی:** `ititadmin1`
* **بەڕێوەبردنی کۆدەکان:** دروستکردنی کۆدی نوێ، چالاک/ناچالاککردن و سڕینەوە.
* **ئامرازی دروستکردنی یاری (Level Builder):** کێشانی خاڵەکان بە کلیک.

### ٤. خەڵات و دیاریکردنی کێ یەکەمە؟ (First Finisher Badge)
* هەر یاریزانێک کە بۆ یەکەم جار یارییەکە تەواو بکات، لەسەر شاشەکەی تاجی زێڕین و ڕاگەیاندنی **"👑 پیرۆزە! تۆ یەکەم کەسیت کە ئەم یارییەت تەواو کرد!"** پێشاندەدرێت.

---

## 🚀 چۆنیەتی کارپێکردن (How to Run)

```bash
node server.js
```
پلاتفۆرمەکە لەسەر پۆرت و بەستەری خوارەوە کاردەکات:
👉 `http://localhost:3000`
